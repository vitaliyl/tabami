## Reporting a Vulnerability

The Tabami team takes security seriously. If you discover a vulnerability or security-sensitive bug in Tabami, please report it responsibly:

1. **Do not disclose the issue publicly** in GitHub issues, PRs, or public discussions.
2. Please submit a report via [GitHub Private Vulnerability Reporting](https://github.com/vitaliyl/tabami/security/advisories/new) on the repository.
3. If private reporting is unavailable, email security concerns directly to the project maintainer.

### What to Include in Your Report

- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) to reproduce the vulnerability.
- Affected components (e.g. Tauri Rust Core, Hanami Backend, SQL Query Executor, or Frontend Webview).
- Any proposed remediation or patch if available.

### Response Timeline

- **Acknowledgment**: Within 48 hours of initial report.
- **Assessment**: Within 7 business days with vulnerability confirmation and severity rating.
- **Remediation**: Patches will be published as part of the next release, accompanied by an advisory.

Thank you for helping keep Tabami secure!
